# Try it: free sites where you practise in the browser

Learn cards ask you to **try** each new idea for 15 to 20 minutes. These free sites let you do that in a browser, with nothing to install.
Every address was checked on 24 November 2026 and opened with status 200.
A site that needs an account says so in its row. Never pay for anything: every site here has a free use that is enough for the course.

## JavaScript, TypeScript and React Native

| Site | Address | Use it for |
|---|---|---|
| Expo Snack | https://snack.expo.dev | Run a React Native app in the browser and on your phone with Expo Go. See [`setup/day1.md`](setup/day1.md) |
| TypeScript Playground | https://www.typescriptlang.org/play | Write TypeScript and see type errors as you type. Select **Run** and read the **Logs** tab |
| TypeScript in 5 minutes | https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html | The handbook's short start, with examples to paste into the Playground |
| React Native: Learn the Basics | https://reactnative.dev/docs/tutorial | Each example has a live editor: change it and see the result |
| React Fundamentals (React Native docs) | https://reactnative.dev/docs/intro-react | Components, props and state, with editable examples |
| Learn React | https://react.dev/learn | Small React examples you can edit and run in place (web, but the ideas are the same) |
| JavaScript Visualizer 9000 | https://www.jsv9000.app/ | Watch the event loop run promises, `setTimeout` and `async` code step by step |
| Exercism TypeScript track | https://exercism.org/tracks/typescript | Short practice problems with tests, and free mentor feedback. Needs a free account |
| React Native Directory | https://reactnative.directory/ | Check whether a library works with Expo Go before you add it |
| Expo tutorial | https://docs.expo.dev/tutorial/introduction/ | Expo's own step-by-step first app |
